# 排班表生成器使用说明

## 功能概述

从 `航班信息` 工作表生成排班表，自动识别航前/短停/航后，并按照规则进行双重预筛选验证和业务筛选。

## 文件说明

| 文件 | 说明 |
|------|------|
| `wps_schedule_generator.py` | 主脚本，在 WPS "效率 → PY脚本编辑器" 运行 |
| `schedule_format.asc` | 格式化脚本（AirScript JavaScript），生成后用来给航班性质上色和分组插空行 |

## 配置说明

### 预筛选（两次独立筛选）

| 筛选方式 | 逻辑 | 配置 |
|----------|------|------|
| 方式A | **只保留**指定机型前缀 | `PRE_FILTER_A_KEEP` = [320系列, 330系列, 350系列] |
| 方式B | 全部保留，**只剔除**指定机型前缀 | `PRE_FILTER_B_EXCLUDE` = 需要剔除的前缀列表 |

- 结果：所有 **A或B** 保留的数据都进入最终排班
- 差异标注在最后一列 `_filter_note`:
  - `一致保留` → A和B都保留
  - `差异：仅方式A保留` → 只有A保留
  - `差异：仅方式B保留` → 只有B保留

### 业务筛选（生成排班后执行）

筛选条件：
1. 机型前缀匹配 `FILTER_MODEL_PREFIXES`（320系列）
2. 航班性质是 **短停** 或 **航后**（航前不筛选）

满足以上两个条件才需要检查：
- 出发站必须在 `["大连", "长春", "长沙黄花", "哈尔滨"]`
- 到达站必须是 `"北京大兴"`

不满足则剔除，满足保留。航前直接保留不筛选。

## 使用步骤

1. 确保工作簿有 `航班信息` 工作表
2. 打开 WPS → 效率 → PY脚本编辑器
3. 打开 `wps_schedule_generator.py` → 点击运行
4. 结果输出到 `排班表` 工作表
5. 如果需要格式化上色，运行 `schedule_format.asc`（JS脚本）

## 筛选逻辑验证

- 如果机型如 `232132121`，不在剔除列表 → 方式B会保留，方式A不保留 → 标注 `差异：仅方式B保留`
- 如果机型在A列表但也在剔除列表 → 方式A保留，方式B剔除 → 标注 `差异：仅方式A保留`
- 如果机型既在A列表又不在剔除列表 → 一致保留
